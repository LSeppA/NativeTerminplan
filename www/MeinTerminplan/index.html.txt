Mit dieser App kannst du den Plan fotografieren ohne dass das Bild in deinen Bildern, sondern nur in der App gespeichert wird. <section class="card" id="anleitung"><h2>So funktioniert die App</h2><ol class="steps"><li><strong>Terminplan erfassen:</strong> Öffne die Scan-Funktion und wähle Kamera oder ein Foto aus deiner Mediathek. <h2 id="fn-posselei-title">¹ Zum Begriff „Posselei“</h2>
<p>Speziell im <strong>Defereggental</strong> (umgangssprachlich oft <em>Defreggen</em>) verschiebt sich die Bedeutung von <strong>„Posselei“</strong> (oder dem Verb <em>posseln</em>) ganz charakteristisch.</p>
<p>Während man im restlichen Tirol bei diesem Begriff meist sofort an Unfug oder Streiche denkt, steht er im Defereggental primär für:</p>
<ul>
<li><strong>Zeitaufwendiges, detailreiches Basteln oder Handwerken:</strong> Es bezeichnet das geduldige, oft kleinteilige Arbeiten mit den Händen. Typischerweise ist damit eine handwerkliche Beschäftigung zu Hause gemeint – etwa das Schnitzen, das Reparieren von kleinen Gebrauchsgegenständen oder das Basteln, besonders in den langen Wintermonaten. <li><strong>Ablenkendes Beschäftigtsein / „Herumnesteln“:</strong> Wenn jemand scheinbar ziellos, aber hochkonzentriert an etwas herumschraubt, richtet oder ausprobiert, dann <em>posselt</em> er.</li>

</ul>
<p><strong>Der sprachliche Hintergrund im Tal:</strong><br>Das Wort ist im Defereggener Dialekt eng mit dem älteren Begriff <em>bosseln</em> (bzw. <em>bossieren</em>) verwandt, was historisch so viel wie „feine, gestaltende Arbeit verrichten“ oder „modellieren“ bedeutet. Weil das Defereggental geografisch lange Zeit sehr isoliert war, haben sich solche sprachlichen Feinheiten dort besonders gut gehalten. Wenn dir jemand im Tal sagt, er hat <em>„heinte a Posselei ghot“</em>, meint er meistens, dass er den Tag über eine recht knifflige, feine Arbeit erledigt hat.</p>

<script>
(() => {
  const video = document.getElementById('demo-video');
  const start = document.querySelector('.video-start');
  const status = document.querySelector('.video-status');
  if (!video || !start || !status) return;

  const showError = () => {
    start.disabled = false;
    start.hidden = false;
    status.textContent = 'Das Video konnte nicht gestartet werden. Bitte versuche es erneut oder lade die Seite neu.';
  };

  start.addEventListener('click', () => {
    start.disabled = true;
    status.textContent = 'Video wird geladen …';
    try {
      // Keep play() directly in the click handler for Safari's user gesture requirement.
      const playback = video.play();
      if (playback && typeof playback.catch === 'function') playback.catch(showError);
    } catch (error) {
      showError();
    }
  });

  video.addEventListener('playing', () => {
    const restoreFocus = document.activeElement === start;
    video.controls = true;
    start.hidden = true;
    start.disabled = false;
    status.textContent = '';
    if (restoreFocus) video.focus({ preventScroll: true });
  });
  video.addEventListener('error', showError);

  // Without JavaScript the video retains its native controls.
  start.hidden = false;
  video.controls = false;
})();
</script>
