# Mein TerminplanTests

Diese Dateien enthalten die ersten Unit-Tests für das aktive Test-Target `Mein TerminplanTests`.

In Xcode:

1. Scheme `Mein Terminplan` auswählen.
2. Test-Aktion starten.
3. Falls Xcode einen anderen App-Modulnamen erzeugt, die Zeile `@testable import Mein_Terminplan` entsprechend anpassen.

Die Tests verwenden das Swift Testing Framework.
